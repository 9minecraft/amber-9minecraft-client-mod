## About this client mod

Amber 9minecraft Client Mod packs in dozens of helpful utility features that give you a huge advantage in the game. This mod gives you a clean menu where you can turn on tools for combat, movement, and building. You can bind any feature to a custom key and change settings on the fly to match your playstyle. Features: \t Clean Interface: Opens an orange-accented menu when you press a single button. \t Custom Shortcuts: Lets you set custom keys for any tool so you can turn them on quickly.
